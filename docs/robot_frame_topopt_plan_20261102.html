01 · BACKGROUND

01왜 동적 고려 위상최적화인가

휴머노이드·협동로봇 암 링크는 수십 ms 급격 슬루잉 하에서 관성 하중이 지배적이다. 정적 설계는 과설계 아니면 파손으로 귀결된다.

경량화

  • 가반하중 대비 자중 최소화
  • 관성 모멘트 감소 → 모터 소형화
  • 목표 체적분율 25%급

고신뢰성 강성·강도

  • 피크 von Mises + COV 평탄화
  • 응력집중·피로 수명 보장
  • 주조·가공 가능 형상

동적 거동 반영

  • 50ms S-curve 가감속 시간 이력
  • 원심·오일러·비틀림 진동 중첩
  • 정적 등가 설계와 수십 % 괴리
02 · RESEARCH SURVEY ①

02최신 연구 조사 — 동적·HCA 계열

문헌 나열이 아니라 독창성·차별성·활용도·연관성, 그리고 우리의 흡수 방안으로 정리한다.

F-ESL — Buzaglo·Pollini 2025 (arXiv:2508.07222) [정독]

  • 독창성: 등가하중 1차항 포함으로 수렴점의 KKT 정류성 보장 — 0차 ESL은 최적점 인식 불가 (Stolpe 2018 반례)
  • 차별성·활용도: 외부 반복당 과도 수반 1회 추가 비용으로 정적 MMA 재사용
  • 흡수: ex09 보정항 + kkt_residual 보고 + 신뢰영역·참응답 수용 판정. 한계 고지: 실증은 사이징 한정

HCA — Tovar 2006 / Penninger 2010 [정독] / Tong 2025 [정독]

  • 독창성: 무구배 SED 균질화, 외부 솔버 결과만으로 갱신 (Tong: 상대변위 −31.02%)
  • 차별성: 수렴 ≠ 최적 — 불동점 다수, 이웃평균은 KKT 위반 (Penninger)
  • 흡수: SE-AHCA 워밍업 + 적응형 PID 게인, 종료조건 KKT 연계
03 · RESEARCH SURVEY ②

03최신 연구 조사 — 응력·옵티마이저·수반해석

응력 — Le 2010 qp-완화 [초록]

  • 독창성: SIMP-motivated 응력 정의로 특이점 해소
  • 흡수: SE-AHCA 기술1 완화식 + P-norm 집계

옵티마이저 — MMA/GCMMA·BESO·Level-Set

과도 수반 — Behrou·Guest, Gen-α/Newmark

  • 흡수: dynamics 시간역행 exact adjoint (비용≈전진 1회)

05 · LOAD CASES

05Loadcase 정의 기술

시간 이력 수백 스텝을 그대로 풀지 않는다. 피크 물리량을 보존하는 소수 대표 하중으로 압축한다.

feq,k = K(x)·uk   ·   대표 스텝: 피크 SE / 피크 팁변위 / 최대 가속·감속 충격   ·   wk ∝ SE(tk)·Δt

추출·병합 규칙

  • 유사 하중 병합 (코사인 유사도 ≥ 0.95)
  • filler 스텝의 가중치 오배정 금지
  • 적분형 가중으로 이중 계수 방지

ESL 부분문제

  • 다중 정하중 문제로 기존 MMA 재사용
  • 1차 보정(F-ESL)으로 KKT 정류성 확보
  • 매 반복 참 동적응답 재평가·수용 판정
06 · ROTATIONAL INERTIA

06축 회전 저항 · 관성 고려 기술

로봇 암 하중의 1차 성분은 관성이다. 질량 보간이 틀리면 하중 자체가 틀린다.

성분수식모듈 반영
원심 인장Fx = m·ω²·LS-curve ω(t) 시간 이력 가진
오일러 접선력Fy = −m·α·L가감속 반전 하중 케이스
편심 토크 우력Fi = T×ri/Σr²허브 링 분배 + ΣF/ΣM assert
회전 관성 지표Izz = Σρ·m·r²정적 vs 동적 설계 교차 비교
질량 보간Du·Olhoff 절단형, q > 1선형 보간 금지 — 강성/질량비 10−6 붕괴, 보이드 스퓨리어스 모드

08 · ROBUSTNESS

08그 외 고려사항

시간 해상도·정합성

  • ωΔt ≤ 0.5 판정 리포트
  • 정합 초기 가속도 a₀ = M⁻¹f₀
  • 최적화↔평가 감쇠계 통일

모달·허브

  • shift-invert 스케일·MAC 모드 식별
  • 보어 passive void / 칼라 passive solid
  • RBE3 철학 하중 분배

수치 무결성

  • 0차 ESL KKT 미보장 → 1차항+신뢰영역
  • HCA 수렴 ≠ 최적 — 잔차 보고

검증 규율

  • 단위 테스트 + 보 이론해 대조
  • 난수·더미 금지, 실측 로그
