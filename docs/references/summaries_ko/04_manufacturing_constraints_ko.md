## 0. 범위와 표기

다루는 제조 제약 5대 구성:

1. 3-field 강건 투영(robust projection)에 의한 최소 고체/공극 길이 스케일(MinS/MinV).
2. Langelaar AM 오버행 필터(빌드 방향 레이어 스윕형, layer-by-layer) — 구배 기반 MaxOA와의 대비 포함.
3. 다축 밀링 제약(음영 투영, shadow projection).
4. 주조 제약(드로우 방향 단조성 + 파팅 평면 분리 투영).
5. 압출 제약(단면 평균 공유 투영).

공통 표기: 설계변수 벡터 `x ∈ [0,1]^N`, 필터된 장 `x̃ = H x`, 투영된 물리 장
`x̄ = h(x̃, η, β)`, 요소 강성 `K_e = E(x̄_e) K_0`, `E(x̄_e) = E_min + x̄_e^p (E_0 − E_min)`.
`H`는 선형 밀도 필터 행렬(§1), `h`는 smoothed Heaviside 투영(§2)이다.

Kumar 2022 설정(2D 직사각형 요소, 캔틸레버 Fig. 2a, MBB, force inverter)이 전제이며,
모든 예제는 MMA(Svanberg)로 푼다. SIMP 연속화 `p = 1.0 → +0.125/40iter`,
Heaviside `β = 1.0 → ×1.5/40iter`, 최대 340 iter, 이동제한 연속화(§2.4)가 기본값이다.

## 1. 선형 밀도 필터와 경계 확장 (공통 전제)

필터 반경 `r_fil`의 가중 평균(Kumar Eq. (1)–(5)):

```
w(x_e, x_j) = max(0, 1 − ‖x_e − x_j‖ / r_fil)
x̃_e = Σ_j x_j v_j w(x_e, x_j) / V^w_e
V^w_e = Σ_j v_j w(x_e, x_j)
H_{ej} = v_j w(x_e, x_j) / V^w_e,  x̃ = H x,  dx̃/dx = Hᵀ
```

경계효과 제거를 위해 설계영역을 메시 확장하고(Fig. 3a), 고정경계 인근의 절단된
필터영역을 수치적으로 확장하여 `V^w_e`를 보정한다(Eq. (2)–(4)). 외력 작용점 주위에는
수치 불안정 방지를 위한 고체 수동 요소(passive solid)를 둔다. `v_j, w, V^w_e`는
최적화 중 불변이므로 `H`를 저장하고 재사용한다.

## 2. 3-field 강건 투영: η_e/η_i/η_d, 고체·공극 지표 I_s/I_v와 미분

### 2.1 투영 함수와 임계값

Wang–Lazarov–Sigmund 강건 정식화(Wang et al. 2011)를 따른다. 요소별 물리밀도
(Kumar Eq. (6)):

```
x̄_e = h(x̃_e, η, β) = [tanh(βη) + tanh(β(x̃_e − η))] / [tanh(βη) + tanh(β(1 − η))]
```

세 임계값은 침식(eroded)·중간(intermediate)·팽창(dilated) 실현을 만든다:

```
η_ero = 0.75,  η_int = 0.50,  η_dil = 0.25   (본 논문 전 예제 고정)
```

`r_min = 0.5 · r_fil` 관계로 MinS = MinV를 맞춘다. 예: 원하는 최소 크기
`r_min = 3` 요소 → `r_fil = 6` (요소 단위). 즉 `topCbeam(200,100,0.4,1.0,6.1)` 호출의
마지막 인자가 필터 반경이다.

요소별 투영 도함수(Kumar Eq. (23)):

```
h'(x̃_e) = dx̄_e/dx̃_e = β · sech²(β(x̃_e − η)) / [tanh(βη) + tanh(β(1 − η))]
dx̄/dx̃ = diag(h'(x̃))   (요소별 독립이므로 대각)
dx̄/dx = diag(h'(x̃)) · H     (전체 야코비안; MMA 감도 전달용)
```

### 2.2 기준 문제 (min-max 강건 문제)

(Kumar Eq. (7)):

```
min_x   c_ero = u_eroᵀ K(x̄_ero) u_ero
s.t.    vᵀ x̄_dil ≤ V*_dil(V*_int)
        0 ≤ x_e ≤ 1
```

- 목적함수는 **침식 설계의 컴플라이언스**(최악 실현)이다.
- 체적 제약은 **팽창 설계**에 걸고, 의도 체적 `V*_int`로부터 10 iter마다
  스케일링한다(Eq. (9)):

```
V*_dil = (vᵀx̄_dil / vᵀx̄_int) · V*_int
```

- 컴플라이언트 메커니즘(force inverter)은 목적함수를
  `min_x max(u_out,ero, u_out,dil)` 형태의 최악-출력변위로 둔다(Eq. (45)).

### 2.3 고체 지표 I_s / 공극 지표 I_v 와 제약 I_s, I_v ≤ ε_s

길이 스케일의 집계(aggregation) 구현은 Fernández et al. 2020 ([26])의 국소 체적
제약을 따른다. 각 요소 `e` 중심 반경 `r_min`(고체) / `r_min,v`(공극) 원형 근방
`Ω_e`에 대해:

```
I_s,e = ( Σ_{j∈Ω_e} v_j x̄_j ) / ( Σ_{j∈Ω_e} v_j )     ∈ [0,1]   (고체 점유율)
I_v,e = 1 − ( Σ_{j∈Ω_e} v_j x̄_j ) / ( Σ_{j∈Ω_e} v_j ) ∈ [0,1]   (공극 점유율)
```

최대 고체 크기(MaxS) 문제는 국소 고체 점유율 상한으로 쓴다(Kumar §2.4, Eqs. (46),
Fernández et al. 2019 [38] 집계 전략 + Guest 2009 [37] 국소 정식화):

```
g_s,e = I_s,e − ε_s ≤ 0   (MaxS, 예제에서 MaxS = 9 요소)
```

공극(캐비티) 최소 크기는 팽창·중간·침식 3장의 공극 점유율 하한 위반을 집계한다.
`p`-mean 집계(§3.3과 동일형)로 전역 제약화:

```
G_s = 2·( (1/N) Σ_e g̃_s,e^p )^{1/p} − (shift) ≤ 0
```

미분(연쇄법칙, 분모-레이아웃):

```
dI_s,e/dx = (1/V_Ωe) · Σ_{j∈Ω_e} v_j · h'(x̃_j) · H_{j,:}
          = (1/V_Ωe) · Hᵀ · diag(h') · (v ◦ 1_{Ω_e})
dG_s/dx = Σ_e (∂G_s/∂g_s,e) · (dI_s,e/dx)
∂G_s/∂g_s,e = 2 · (1/N)^{1/p} · (Σ_k g̃_s,k^p)^{1/p − 1} · g̃_s,e^{p−1} · (∂g̃/∂g)
```

`V_Ωe = Σ_{j∈Ω_e} v_j`, `◦`는 Hadamard 곱, `1_{Ω_e}`는 근방 지시벡터이다.
Kumar의 MaxSize MATLAB 코드(Appendix D)가 이 국소 체적→집계→강건 3장 적용
(`g_ms(x̄_int) ≤ 0, g_ms(x̄_dil) ≤ 0`) 파이프라인을 구현한다.

### 2.4 삼각형 비자립부 검출용 지표 I_c (PP 단계와 연결)

§3.2의 후처리 검출기는 세 지표의 곱을 쓴다(Fig. 8):

```
I_c,e = g_e · c_e · I_v,e   (요소별 곱; Fig. 8h)
```

- `g_e`: 편이된 국소 오버행 위반량(§3.1 Eq. (20)), `[0,1]`. 자립 불가 삼각형 끝단에서
  구배가 빌드방향과 직교 → `g_e = 1`.
- `c_e = exp(−c̄ · u_eᵀK_e u_e)`: 저변형에너지 강조(Eq. (35)). 변형에너지가 없으면 1.
- `I_v,e`: 원형영역 `Ω` 내 공극분율 지시자(Eq. (36)):

```
I_v,e = 1  if Σ_{j∈Ω} v_j(1 − x̄_j) ≤ v̄ · Σ_{j∈Ω} v_j
        0  otherwise
```

`v̄ ∈ (0.5(r̄+2)/(2r̄)]` 임계. 검출 후 Heaviside(`h(I_c,η,β_v)`) → 반경 `r_fil` 원으로
최대값 필터(`I_r` = 원내 `max h(I_c)`) → 불리언 제거(Eq. (37)):

```
x̂_e = min(max(x_e − I_r,e, 0), 1)
```

## 3. Langelaar AM 오버행 필터와 Kumar 구배 기반 MaxOA

두 계열을 구분한다. (a) **Langelaar 레이어 스윕 필터**(global, layer-by-layer:
`14_Langelaar2016`, `15_Langelaar2017` — 미확보이므로 Kumar의 인용·서술에 근거한
교차 정리), (b) **Kumar 구배 기반 MaxOA 제약**(local, 본 논문의 직접 기여).

### 3.1 Kumar 구배 기반 MaxOA (직접 원문)

Prewitt 연산자(3×3 마스크, Kumar Eqs. (12)–(16))로 요소별 구조 구배:

```
δ^x_e = Σ_j x̄_j D^x_{ej},   δ^y_e = Σ_j x̄_j D^y_{ej}
δ_e = (δ^x_e, δ^y_e) = (D_x x̄)_e, (D_y x̄)_e
dδ^x/dx̄ = D_xᵀ,  dδ^y/dx̄ = D_yᵀ
```

`D^x_{ej} = (x_j − x_e)/|x_j − x_e|` (|Δx|≤h, |Δy|≤h 영역, Eq. (13)), `D^y`도
대칭형(Eq. (14)). 정규화(Eq. (17)–(18)):

```
ϱ_e = δ_e / δ̄_e,   δ̄_e = 1/‖δ_e‖  if ‖δ_e‖ ≥ ε_n else 0
‖δ_e‖ = √((δ^x_e)² + (δ^y_e)²)
```

`ε_n`은 특이점 회피 + 회색영역 분할 억제용 연속화 파라미터
(`ε_n: 0.3·‖δ‖_max의 10% → 30%`, GBOHC 코드 line 29).

국소 오버행 위반(Eq. (19), Fig. 6):

```
g_e = ϱ_eᵀb − ϱ_0ᵀb ≤ 0
```

`b`는 빌드방향 단위벡터, `ϱ_0`는 기준면 구배(임계각 `α` 반영).
회전된 빌드방향(Eqs. (32)–(33)):

```
b(θ) = (cos(θ + π/2), sin(θ + π/2))
ϱ_0(θ) = (cos(θ + π/2 − α), sin(θ + π/2 − α))
```

`[0,1]` 편이(Eq. (20)) 후 `p`-mean 집계(Eq. (21)):

```
g̃_e = (1/2)(g_e + ϱ_0ᵀb + 1)
G = 2·((1/N) Σ_e g̃_e^p)^{1/p} − ϱ_0ᵀb − 1 ≤ 0
```

감도(Kumar Eqs. (22)–(30), 행렬곱 1회로 축약한 최종형 Eq. (29)):

```
dG/dx = Hᵀ · diag(h'(x̃)) · dG/dx̄
dG/dx̄ = D_xᵀ(ξ ◦ w) + D_yᵀ(ζ ◦ w)
ξ_e = b_x − b_x·ϱ̄^x_e·ϱ^x_e − b_y·ϱ̄^y_e·ϱ^x_e   (Eq. (30)의 a_x)
ζ_e = b_y − b_y·ϱ̄^y_e·ϱ^y_e − b_x·ϱ̄^x_e·ϱ^y_e   (Eq. (30)의 a_y)
w_e = 0.5 · δ̄_e ◦ G'_e
G'_e = p^{−1}·((1/N)Σ_k g̃_k^p)^{1/p − 1}·(1/N)·g̃_e^{p−1}   (Eq. (24))
```

풀체인(Eq. (26))은 `dϱ/dx̄, d‖δ‖/dx̄, dδ̄/d‖δ‖` 항으로 구성되며(Eqs. (27a)–(27g)),
Hadamard 정리로 위 축약형이 된다. `p = 60`(단일 방향), 다방향 집계 §3.3에서는
표 3 기준 `p = 10–80`을 쓴다.

오버행 제약 3장 적용 문제(Eq. (31)):

```
min c_ero  s.t. vᵀx̄_dil ≤ V*_dil, G(x̄_ero) ≤ 0, G(x̄_int) ≤ 0, G(x̄_dil) ≤ 0
```

단, `r_min > 3`이면 침식·중간장의 re-entrant 코너에서 MaxOA와 MinV가 기하학적으로
충돌하므로 **팽창장에만** `G(x̄_dil) ≤ 0`을 건다(§1.2.4, Fig. 10). 팽창장은 최소
공극 크기를 갖지 않으므로 충돌이 없다.

### 3.2 Langelaar AM 필터 — 빌드방향 레이어, 지지영역 S, softmax S_max, smooth minimum ρ_AM, 역방향 스윕 J_AMᵀv 유도

> 본 절은 미확보 문헌(`14_Langelaar2016`, `15_Langelaar2017`)의 교차 정리이다.
> Kumar 2022가 인용한 바(Refs [11][19][23])와 오픈액세스 후속 서술에 근거하며,
> 기호는 Langelaar 계열의 표준형으로 재서술했다. 원문 직접 인용이 아니다.

빌드방향을 `+z`(레이어 `k = 1…n_z`, 베이스플레이트 `k = 0`은 완전 지지)라 한다.
청사진(blueprint) 밀도 `ρ_BP = x̄`(투영 후 장)가 입력, 인쇄가능(printable) 밀도
`ρ_AM`이 출력인 **전방향(순방향) 스윕 필터**이다.

**(a) 지지영역 S.** 요소 `i` (레이어 `k`)의 지지 후보는 바로 아래 레이어 `k−1`에서
45° 오버행 콘(임계각 `α = 45°` 표준) 안에 드는 요소 집합:

```
S_i = { j ∈ layer k−1 : ‖x_j − x_i‖_{xy} ≤ Δz · tan α }   (2D: {j−1, j, j+1})
```

`Δz`는 레이어 두께(요소 높이). 베이스플레이트 위 첫 레이어(`k = 1`)는 `S_max = 1`.

**(b) softmax 지지 최대값 S_max.** 지지 후보 중 최대 지지량을 smooth max로 근사:

```
S_max,i = ( Σ_{j∈S_i} ρ_AM,j^P )^{1/P}        (P → ∞에서 max; 표준 P ≈ 40)
```

또는 normalized softmax형 `S_max,i = Σ w_j ρ_AM,j / Σ w_j`, `w_j = exp(P·ρ_AM,j)`.
`ρ_AM,j`는 **이미 인쇄된 아래층의 출력**을 쓰므로 필터는 아래→위 순방향 재귀이다.

**(c) smooth minimum ρ_AM.** 인쇄 밀도는 청사진과 지지량의 smooth minimum:

```
ρ_AM,i = smin(ρ_BP,i, S_max,i)
smin(a,b) = (1/2)(a + b − √((a−b)² + ε_s) + √ε_s),   ε_s ≪ 1 (예 10⁻⁴)
```

`smin`의 편미분:

```
∂smin/∂a = (1/2)(1 − (a−b)/√((a−b)² + ε_s))
∂smin/∂b = (1/2)(1 + (a−b)/√((a−b)² + ε_s))
```

베이스층: `ρ_AM,i = ρ_BP,i` (`k = 1`).

**(d) 역방향 스윕随伴 — J_AMᵀv 유도.** 필터 전체를 `ρ_AM = F(ρ_BP)`라 쓰면
야코비안 `J_AM = ∂ρ_AM/∂ρ_BP`는 아래층→위층 의존으로 **블록 하삼각**(+대각)이다.
목적·제약 감도는随伴 벡터를 **위층→아래층 역방향 스윕**으로 전파한다.
임의随伴 시드 `v = ∂f/∂ρ_AM`에 대해 `u = J_AMᵀ v`를 구한다:

```
u_i = v_i · s_a,i + Σ_{k: i∈S_k} v_k · s_b,k · (∂S_max,k/∂ρ_AM,i)
s_a,i = ∂smin/∂a|_i,  s_b,i = ∂smin/∂b|_i
∂S_max,k/∂ρ_AM,i = ρ_AM,i^{P−1} / (Σ_{j∈S_k} ρ_AM,j^P)^{1−1/P}   (i ∈ S_k)
```

역방향 스윕 알고리즘 (`k = n_z → 1`):

```
λ_i ← v_i · s_a,i                                   (직접항)
for k = n_z … 2:
  for i ∈ layer k−1:
    λ_i ← λ_i + Σ_{k': i∈S_{k'}} λ̃_{k'} · (∂S_max,k'/∂ρ_AM,i),  λ̃_{k'} = v_{k'}·s_b,k'
최종  u = λ  (베이스층 포함),  df/dρ_BP = u ◦ h' ◦ (H의 전치 전파)
```

즉 순방향은 지지정보가 위로 흐르고, 역방향은 감도가 아래로 흐른다. 이것이
Langelaar AM 필터가 **자기지지 위반을 구조적으로 제거**하는 이유이며, Kumar 구배
제약이 허용하는 비자립 삼각형(Fig. 2b, Table 1 (1,1))과의 결정적 차이이다.
Kumar는 이 약점을 에너지 기반 free-evolution + PP 불리언 제거(§2.4 본 요약)로
우회한다: `m_L = 1.0 (‖δ‖ ≤ ε_m), 0.001 (그 외)` 표면만 진화(Eq. (34)),
`N_free = 2–10`(Table 3).

**(e) 빌드 방향 동시 최적화 (Langelaar 2018 [23] 교차 정리).** 후보 방향
`{θ_m}_{m=1..N_d}`에 대한 `G(θ_m)` 중 최소제약 방향을 `r`-norm으로 선택
(Kumar Eqs. (38)–(39)):

```
t_m = 1 − 0.5(G_m + ϱ_0ᵀb + 1)
G* = 1 − 2·(Σ_m t_m^r)^{1/r} − ϱ_0ᵀb ≤ 0,   r = 15–40 (Table 3)
dG*/dx = Hᵀ(h'(x̃) ◦ (D_xᵀ(A_x(G*'ᵀ)) + D_yᵀ(A_y(G*'ᵀ))))   (Eq. (41))
A_x(m,e) = a_x,e(θ_m)·B_e(θ_m),  G*' = dG*/dG  (Eqs. (42)–(43))
```

`a_x, a_y, B`는 Eq. (30)형 계수의 방향별 평가이다. 활성집합(active set, 하위 10%
최소제약 방향만, Ψ)으로 대규모 방향(`N_d > 100`) 비용을 절감한다.
측정 예(캔틸레버, Table 2): 기준 0.60 s/iter·158 s → 단일 `G(x̄_dil)` 0.87 s/iter·297 s
→ 180 방향 1.82 s/iter·618 s (Dell Precision 5510, MATLAB R2015a).

관찰(§1.3, §2.1–2.2): 최적 방향은 **기준 설계를 최소로 수정하는 방향**
(캔틸레버 `θ* ≈ 90° ± 2°`, Langelaar [23]의 `90° ± 5°`와 일치)으로 수렴하며,
구조성능 최대 방향이 아닐 수 있다. MBB 4방향 예에서 `θ* = 60°` 설계가 2방향
설계보다 컴플라이언스가 나쁘다(Fig. 17a vs Fig. 16c).

### 3.3 대칭 처리 (MBB/force inverter)

대칭선을 기준으로 국소 제약을 미러 집계한다(§2.2–2.3):

```
g_e^{sym} = g_e(θ) + g_e(360° − θ)
```

필터 경계 확장도 대칭 반영. 빌드방향 후보는 대칭 절반 구간에서 정의
(`θ_m = 180°(m−1)/(N_d−1)`).

## 4. 다축 밀링 제약 — 음영 투영과 야코비안

> 근거: METHODS 서베이 §10 "Casting/milling: only 2006/2011 references surfaced".
> 아래는 해당 고전 계열(표준 음영/가시성 투영)의 교차 정리이며, Kumar 직접 내용이 아니다.

### 4.1 음영(shadow) 투영

밀링 공구가 접근 방향 `d_m` (`m = 1…M`, 예: ±x, ±y, ±z 6방향) 으로 직선 접근한다고
가정한다. 청사진 밀도 `ρ_BP`로부터 방향별 가공가능 장을 **광선 누적 최대치**로 정의:

```
ρ_mach^{(m)}_i = max_{j ∈ R_m(i)} ρ_BP,j
R_m(i) = { j : j는 i에서 −d_m 방향 역광선상의 요소 }   (i 자신 포함)
```

smooth max 근사 (P-norm 또는 Kreisselmeier–Steinhauser):

```
ρ_mach^{(m)}_i = ( Σ_{j∈R_m(i)} ρ_BP,j^Q )^{1/Q},   Q ≈ 40–80
```

또는 누적형 integrating shadow: 공구 진입면에서부터 running max를 전파.
최종 가공가능 밀도는 모든 공구 방향의 **교집합**(smooth minimum):

```
ρ_mill,i = smin_m( ρ_mach^{(1)}_i, …, ρ_mach^{(M)}_i )
smin_m = −(1/Q')·ln( Σ_m exp(−Q'·ρ_mach^{(m)}_i) )   (KS 음형) 또는 재귀 smin
```

물리장으로는 `ρ_mill`을 쓴다: `E_e = E(ρ_mill,e)`.

### 4.2 야코비안 (정방향·역방향)

방향별 야코비안 `J^{(m)} = ∂ρ_mach^{(m)}/∂ρ_BP`는 광선상 의존으로 **희소 상·하삼각
혼합**(방향별 정렬 순서에 따라 일방향 대각 포함)이다:

```
J^{(m)}_{ij} = ρ_BP,j^{Q−1} / (Σ_{k∈R_m(i)} ρ_BP,k^Q)^{1−1/Q}   if j ∈ R_m(i), else 0
∂ρ_mill,i/∂ρ_mach^{(m)}_i = exp(−Q'·ρ_mach^{(m)}_i) / Σ_n exp(−Q'·ρ_mach^{(n)}_i)
```

전체 전파:

```
∂f/∂ρ_BP = Σ_m J^{(m)ᵀ} · diag(∂ρ_mill/∂ρ_mach^{(m)}) · (∂f/∂ρ_mill)
```

구현은 광선 역순 스윕(각 방향 진입면 반대쪽부터 누적随伴 전파)으로 `O(M·N)`이며,
AM 필터 역스윕(§3.2 (d))과 동일한随伴 구조이다. 밀로 접근 불가한 내부 공동은
`ρ_mill`에서 자동 제거되므로 별도 공극 제약을 두지 않아도 언더컷이 원천 차단된다.
대신 깊은 포켓의 공구 간섭(길이/직경비)은 본 모델에 없으며 별도 종횡비 제약이
필요함을 명시한다.

## 5. 주조 제약 — 드로우 방향 단조성과 파팅 평면 분리 투영

> 근거: §4와 동일(고전 주조 제약 교차 정리). 기호는 표준 단조-분할형으로 재서술.

### 5.1 드로우 방향 단조성

드로우(형개방) 방향을 `+z`, 파팅 평면을 `z = z_0`이라 한다. 상형(`z > z_0`)에서는
위로 갈수록 밀도가 감소(언더컷 금지), 하형에서는 아래로 갈수록 감소해야 한다:

```
상형: ρ(z + Δz) ≤ ρ(z)   (z > z_0, 위로 갈수록 비증가)
하형: ρ(z − Δz) ≤ ρ(z)   (z < z_0, 아래로 갈수록 비증가)
```

구현은 한쪽 방향 누적 최소값(cumulative minimum) 투영. 상형 예(위에서 아래로 스윕):

```
ρ_cast,i = min( ρ_BP,i, ρ_cast,parent(i) ),   parent = 바로 위 이웃 (z + Δz)
```

smooth minimum (smin, §3.2와 동일형, 파라미터 `ε_c`):

```
ρ_cast,i = smin(ρ_BP,i, ρ_cast,parent(i); ε_c)
∂ρ_cast,i/∂ρ_BP,i = ∂smin/∂a|_i
∂ρ_cast,i/∂ρ_cast,parent = ∂smin/∂b|_i
```

随伴은 파팅면에서 먼 쪽 → 파팅면 쪽 역스윕(AM 역스윕의 단조 버전):

```
λ_i = v_i·(∂smin/∂a|_i) + λ_child(i)·(∂smin/∂b|_child(i))
```

`child(i)`는 `i`를 parent로 삼는 이웃(아래층). 하형은 스윕 방향만 반전한다.

### 5.2 파팅 평면 분리 투영

상·하형을 **독립 변수열**로 둔다: `ρ_BP = (ρ_BP^+, ρ_BP^−)`. 파팅면 요소열은 공유
(양형이 같은 값을 보도록 등식 또는 평균 구속):

```
ρ_parting = (ρ_BP^+|_{z_0} + ρ_BP^−|_{z_0}) / 2    (공유 투영)
```

각 형의 단조 투영을 독립 적용 후 결합:

```
ρ_cast = concat( F^+(ρ_BP^+, ↓상형), F^−(ρ_BP^−, ↓하형) )
```

야코비안은 블록 대각(`J = blkdiag(J^+, J^−)`, 파팅 공유행만 1/2 가중 평균행):

```
∂f/∂ρ_BP^+ = J^{+ᵀ}v^+ + (1/2)·(∂f/∂ρ_parting)|_{z_0}
∂f/∂ρ_BP^− = J^{−ᵀ}v^− + (1/2)·(∂f/∂ρ_parting)|_{z_0}
```

파팅면 위치 `z_0` 자체를 설계변수로 두는 확장(Langelaar 2019 [26] 계열이 다루는
후속 주제 — 미확보이므로 명칭만 기록)은 본 요약의 범위를 벗어난다.

## 6. 압출 제약 — 단면 평균 공유 투영과 전치

> 근거: 고전 압출/프리즘 제약(교차 정리). 압출 방향으로 단면이 일정해야 하는
> 프리즘 부품(방열판, 압출 프로파일)용이다.

### 6.1 공유 투영 (정방향)

압출 방향을 `z`라 한다. 각 `(x, y)` 기둥(column) `C_{xy} = {e : (x_e, y_e) = (x, y)}`
내 청사진 값들을 평균하여 기둥 전체에 방송한다:

```
ρ̄_col(x, y) = ( Σ_{e∈C_{xy}} v_e · ρ_BP,e ) / ( Σ_{e∈C_{xy}} v_e )
ρ_ext,e = ρ̄_col(x_e, y_e)    ∀e ∈ C_{xy}
```

행렬형: `ρ_ext = P ρ_BP`, `P = B·A` (`A`: 기둥 평균행, `B`: 방송행).
`P`는 직교투영(`P² = P`, 대칭)이다.

### 6.2 전치 (역방향 감도)

`P`가 대칭이므로 전치는 자기 자신이다:

```
∂f/∂ρ_BP = Pᵀ · (∂f/∂ρ_ext) = P · (∂f/∂ρ_ext)
```

즉随伴 벡터를 같은 기둥 평균–방송 연산에 다시 통과시키면 된다:

```
(∂f/∂ρ_BP)_e = ( Σ_{k∈C_{x_e y_e}} v_k · (∂f/∂ρ_ext)_k ) / ( Σ_{k∈C_{x_e y_e}} v_k )
```

구현 1줄: 감도장을 기둥 평균한 뒤 방송. 압출면(다이 입구) 쪽 1층을 마스터 변수로
두고 나머지를 종속시키는 축소 구현과 수학적으로 동일하다.
