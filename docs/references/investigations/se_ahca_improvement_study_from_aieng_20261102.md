# SE-AHCA 개선 연구 기록 (aieng 쪽 재구현 검증)

작성: 2026-11-02. 작성 주체: aieng/topopt 담당 에이전트. 이 문서는 wht_topopt의 SE-AHCA가 MBB 벤치마크에서 회색(gray) 결과를 내는
원인을 aieng 쪽에서 규칙을 재구현해 분리 검증한 기록이며, wht_topopt 에이전트가 이를 보고 개선 작업을 할 수 있도록 정리했다.
두 프로젝트는 서로 코드를 import하지 않는다. 아래 코드는 아이디어 설명용이며 그대로 복사하지 말고 wht_topopt 구조에 맞게 재구현한다.

## 1. 문제

`examples/outputs_v1/beams/mbb_benchmark_suite.png`의 SE-AHCA: C = 595.29, 회색도 0.210, 35회.
같은 그림의 MMA 257.99, GCMMA 266.03, SEMDOT 230.65, BESO 237.63과 비교해 컴플라이언스가 2배 이상이고
부재가 형성되지 않는 매끈한 구배(그라데이션) 모양이다. 컴플라이언스 곡선은 35회까지 계속 내려가고 있었다.

## 2. 읽은 코드

- `algorithms/hca.py`: `StressEnergyAdaptiveHCA` (신호 = (1-eta) U_norm + eta phi_stress, tanh 오차, 요소별 PID + 적응 게인, 체적 이분법).
- `examples/ex06_beams_benchmark_suite.py:766-835` `run_se_ahca`: 호출부.
- `examples/ex07_ge_bracket_advanced_algorithms.py:297-381`: GE 브라켓에서의 호출부.

## 3. 가설 (코드 독해)

1. ex06 호출부는 `fem.compute_unit_element_compliance(u)`를 신호로 쓴다. 단위 탄성계수 에너지 u_e^T K0 u_e라 밀도에 무관하다.
   에너지 밀도가 균일한 상태가 평형이라는 HCA 규칙은 중간 밀도로도 달성된다. 0/1로 미는 힘이 없다.
2. `SEAHCAConfig.sigma_allow` 기본값은 250e6(Pa 기준)인데 ex06은 `e0=1.0` 무차원 계산이다. von Mises가 1 안팎이라 응력비가 약 1e-16이 되어
   `(1-eta) U + eta Sigma`에서 응력 항이 사라진다. 응력 제어가 사실상 꺼져 있다.
3. 신호에 밀도 필터(`neighborhood_filter_fn=d_filt.forward`)와 2회 이동평균(`history_window=2`)을 겹쳐 쓰고, 밀도에도 다시 필터가 걸린다.
4. `step()`의 체적 이분법은 `forward_projection_fn`이 없으면 투영 이전의 x에서 돈다. 투영을 쓰면 실제 체적과 어긋난다 (ex06은 투영 자체를 쓰지 않는다).

## 4. 검증 실험

aieng 쪽에 같은 규칙(tanh 오차, 요소별 적응 게인 kp 0.18 (0.02~0.38), ki 0.03, kd 0.02, move 0.18, 체적 이분법)을 재구현하고
신호와 투영만 바꿔 비교했다. 문제: half MBB 180x60 (요소 1x1), V = 0.4, rmin = 2.4, SIMP 페널티 3, 100회.
재구현 위치(참고용): `aieng/src/aieng/topopt/hca.py`, 실험 `aieng/examples/topopt_hca_ablation.py`, 그림 `aieng/examples/output/hca_ablation/hca_ablation.png`.

| 변형 | 신호 | 투영 | C | V | 회색도 |
|---|---|---|---|---|---|
| A | 단위 에너지, 신호 필터, 평균 2 (ex06 현재 설정) | 없음 | 583.35 | 0.400 | 0.208 |
| B | 단위 에너지, 필터 없음 | 없음 | 599.36 | 0.400 | 0.210 |
| C | 페널티 x^(p-1) u0 / v | 없음 | 261.30 | 0.400 | 0.049 |
| D | 페널티 x^(p-1) u0 / v | Heaviside beta 1 -> 8 (20회마다 2배) | 238.64 | 0.400 | 0.012 |
| E | 단위 에너지 | Heaviside beta 1 -> 8 | 723.18 | 0.400 | 0.206 |
| - | MMA 기준 (투영 없음) | - | 253.88 | 0.400 | 0.043 |

해석:
- A가 ex06의 SE-AHCA 그림 (C 595, 회색도 0.210)과 거의 같게 재현되었다. 원인이 호출부와 신호에 있다는 증거다.
- 신호만 페널티 형태로 바꾸면(C) 트러스가 형성되고 MMA와 비슷한 컴플라이언스가 된다.
- 투영만 붙여서는(E) 소용이 없다. 투영은 신호가 올바를 때만 효과가 있다 (D).
- D의 컴플라이언스가 MMA보다 낮은 것은 투영 유무 조건이 달라서 직접 비교는 아니다 (MMA 기준은 투영 없음).
- 이 실험은 응력 항 없이 컴플라이언스 신호만 본 것이다. 응력 항은 이번에 검증하지 않았다.

## 5. 핵심 이유 (HCA가 0/1이 되는 조건)

신호 s_e가 요소 밀도에 비례해 커지면(페널티된 에너지) 한 요소가 밀도를 잃을수록 자신의 신호도 줄어 더 잃는다. 이 양의 되먹임이
0 또는 1로의 불안정성을 만든다. 밀도에 무관한 신호는 이 되먹임이 없어 균일 평형(회색)이 안정하다.
ex07(GE)의 신호는 `E_field * elem_energy` = rho^p 비례로 이미 페널티가 있어 이 조건을 만족한다. 그래서 GE에서는 244 g, p99.5 735 MPa 통과가 나온 것으로 이해된다.
(ex06만 단위 에너지를 쓴다. 두 예제 사이의 신호 정의 불일치가 있다.)

## 6. 개선 제안 (우선순위)

1. ex06 `run_se_ahca`: 신호를 `rho_phys**p * u0 / v` 또는 `rho_phys**(p-1) * u0 / v`로 바꾼다.
   (aieng 실험은 후자를 썼다. 어느 쪽이 나은지는 비교해 볼 만하다.)
2. `sigma_allow`를 문제 단위에 맞춘다 (MPa 문제면 항복응력, 무차원이면 기준 응력의 비율). 단위 불일치를 경고하는 검사를 `SEAHCAConfig` 쪽에 넣는 것이 좋다.
3. `step()`에 `forward_projection_fn`을 전달하고(필터 -> Heaviside) beta를 20회마다 2배, 최대 8까지 올린다. 이분법의 체적은 투영된 밀도로 계산한다.
4. 신호에 걸리는 평활화는 하나만 쓴다 (밀도 필터 또는 이동평균). 두 가지를 겹치면 경계가 뭉개진다.
5. 반복을 100회 이상으로 하고 종료 조건에 컴플라이언스 정체를 넣는다. 35회는 이 규칙에 모자란다 (게인 0.02~0.38, tanh 포화).
6. 위 변경 후 같은 MBB 표를 다시 생성하고 A/C/D에 해당하는 절제 실험(ablation)을 `docs/benchmarks/`에 남긴다.

## 7. 확인하지 못한 것

- wht_topopt를 직접 실행하지 않았다. 코드 독해와 aieng 쪽 재구현으로 얻은 결론이다.
- 응력 항을 포함한 SE-AHCA가 GE 브라켓에서 응력 제약 MMA와 같은 질량 대비 응력을 내는지는 비교하지 않았다.
  참고로 aieng의 GE 응력 제약 MMA (MC60, 대칭, AM, 150회): 256 g, 최대 von Mises 920/772/752/504 MPa, 99.5% 813/589/601/429 MPa.
  wht 보고서는 p99.5만 적으므로 최대값도 같이 적어야 비교가 된다.
- 3D와 2.5D 압출 경우는 검증하지 않았다.

## 8. 정정 (2026-11-03, 코드 리뷰 후)

- 5절의 "ex07은 조건을 만족한다"는 컴플라이언스 신호에 한한 말이다. ex07은 페널티 응력(`E_field` 사용)을 `von_mises_unpenalized_cases`로 넘겨 `rho^q`가 또 곱해지므로, 응력 항은 의도대로 작동하지 않는다 (`code_review_wht_topopt_20261103.md` R4).
- 따라서 7절의 "244 g, p99.5 735 MPa"는 이 결함이 있는 상태의 값이다. 다른 옵티마이저와의 비교 근거로 쓰지 않는다 (R2도 참고).
- 우선순위는 `code_review_wht_topopt_20261103.md` 6절을 따른다.
